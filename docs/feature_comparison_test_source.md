# 決済端末アプリ 機能仕様書

## 対応決済方法

本アプリケーションは以下の決済方法に対応しています。

### 対応済み決済方法

| 決済方法 | 表示名 | 対応状況 |
|---------|--------|---------|
| CREDIT_CARD | クレジットカード（EMV IC / 磁気） | ✓ 対応 |
| SUICA | Suica（交通系IC） | ✓ 対応 |
| QR_CODE | QR決済（PayPay/LINE Pay等） | ✓ 対応 |
| WAON | WAON | ✓ 対応 |
| NANACO | nanaco | ✓ 対応 |
| RAKUTEN_EDY | 楽天Edy | ✓ 対応 |

### 未対応決済方法

| 決済方法 | 表示名 | 対応状況 |
|---------|--------|---------|
| CASH | 現金支払 | × 未対応 |
| PREPAID | プリペイド（Intent外部連携） | × 未対応 |

## 決済方法詳細

### クレジットカード決済
- EMV IC チップ読み取りに対応
- 磁気ストライプ読み取りに対応

### 交通系IC決済
- Suica を含む交通系ICカードに対応

### QR決済
- PayPay
- LINE Pay
- その他QRコード決済サービスに対応

### 電子マネー決済
- WAON
- nanaco
- 楽天Edy

## 備考

本仕様は、LLMによる仕様書自動生成のテスト用として作成されており、実際のアプリケーションより少ない決済方法のみを定義しています。
