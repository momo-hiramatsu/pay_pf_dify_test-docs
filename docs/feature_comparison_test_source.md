# 決済端末アプリ 機能仕様書

## 対応決済方法

本アプリケーションは以下の決済方法に対応しています。

### 対応済み決済方法

| 決済方法 | 表示名 | 対応状況 |
|---------|--------|---------|
| CREDIT_CARD | クレジットカード（EMV IC / 磁気） | ✓ 対応 |
| SUICA | Suica（交通系IC） | ✓ 対応 |
| QR_CODE | QR決済（PayPay/LINE Pay等） | ✓ 対応 |
| WAON | WAON | ✓ 対応 |
| NANACO | nanaco | ✓ 対応 |
| RAKUTEN_EDY | 楽天Edy | ✓ 対応 |
| APPLE_PAY | Apple Pay | ✓ 対応 |

### 未対応決済方法

| 決済方法 | 表示名 | 対応状況 |
|---------|--------|---------|
| CASH | 現金支払 | × 未対応 |
| PREPAID | プリペイド（Intent外部連携） | × 未対応 |

### クレジットカード決済

- 磁気ストライプ読み取りに対応

- Apple Pay

## 分乗決済機能

本アプリケーションは、複数人で1回の乗車料金を分割して支払う「分乗決済」機能に対応しています。タクシー利用時などで、複数の決済方法を組み合わせて支払うことが可能です。

### 機能概要

- 総額に対して、複数の決済方法で分割支払いが可能
- 各分割に対して、対応済み決済方法のみ利用可能
- 分割金額の合計が総額を超えないよう制御

### 分割支払い登録

**機能**: `addSplit(method: PaymentMethod, amount: Int)`

分割支払いエントリを追加します。

**バリデーション**:
- 指定された決済方法が分乗決済に対応しているか確認
- 分割金額が正の整数であることを確認
- 現在の分割金額合計 + 追加金額が総額を超えないことを確認

**戻り値**:
- `SplitResult.Success`: 分割追加成功時、現在の分割リストを返却
- `SplitResult.Failure`: 分割追加失敗時、エラー理由を返却

### 決済状況確認

**機能**: `isFullySettled()`

分割金額の合計が総額と一致しているかを判定します。

**機能**: `remainingAmount()`

残りの未分割金額を返却します。

### 決済実行

**機能**: `settleAll()`

登録された全ての分割支払いを実行します。各分割エントリに対して決済処理を行い、結果のリストを返却します。

## レシート印字機能

決済端末が発行するレシートの印字内容を組み立てる機能を提供します。

### レシート生成

**機能**: `buildReceiptText(splits: List<SplitEntry>, totalAmount: Int)`

分乗決済の明細をテキスト形式で生成します。

**出力内容**:
- ヘッダー: "=== ご利用明細 ==="
- 合計金額表示
- 分乗内訳セクション
  - 各分割の番号（1人目、2人目...）
  - 決済方法の表示名
  - 分割金額
- フッター: "=================="

**出力例**:
```
=== ご利用明細 ===
合計金額: 3000円
--- 分乗内訳 ---
1人目: クレジットカード（EMV IC / 磁気） 1500円
2人目: Suica（交通系IC） 1500円
==================
```
